# Raytracing

A simple raytracer: one sphere lit by an orbiting light source.
Renders through SDL2.

## Requirements

clang, SDL2

## Running

```bash
make raytracing
./build/raytracing
```

Optimized under O2:

```bash
make raytracing-opt
./build/raytracing-opt
```

## Cleaning

```bash
make clean
```
